# BI-CAR PARTS v72 — аудит перед production

## Перевірено та виправлено

- Production-вхід адміністратора працює через серверний JWT, а не через старий демо-пароль.
- Реєстрація та вхід клієнта перенесені на сервер: bcrypt + JWT.
- VIN можна визначити без входу, але категорії та артикули AutoPartsAPI захищені customer JWT.
- AutoPartsAPI key зберігається тільки на сервері.
- Публічний API товарів не повертає закупівельну ціну, джерело, внутрішні коди чи службові поля.
- Онлайн-замовлення записуються у PostgreSQL, після успішного запису запускаються Telegram/Email/WebPush.
- Онлайн-замовлення доступні адміністратору з сервера; клієнтська історія замовлень теж читається із сервера.
- Збережені авто клієнта синхронізуються із сервером.
- Запити на підбір запчастин записуються в PostgreSQL і показуються в адмінці.
- Онлайн-чат: Socket.IO + PostgreSQL, online/offline, typing, unread, час, звук, файли та offline auto-reply.
- PostgreSQL і Node.js app не відкривають свої порти назовні у production; зовнішній доступ іде через Caddy.
- Caddy забезпечує HTTPS і WebSocket proxy.
- У production встановлено trust proxy = 1.
- Додано перевірку production-конфігурації та секретів під час старту.
- Додано health endpoints і graceful shutdown.
- Додано rate-limit для VIN/AutoPartsAPI та обмеження кешу.
- Додано мережеві таймаути для Telegram, SMTP та WebPush.
- Додано backup/restore PostgreSQL + завантажених файлів.
- Додано інтерактивний one-command deployment.

## Межа v72

v72 підготовлена до production як публічний магазин і серверне ядро: авторизація, каталог, замовлення, VIN/AutoPartsAPI, чат, сповіщення, клієнтські авто/замовлення та запити на підбір.

Деякі старі ERP-функції ще залишаються legacy/localStorage і не є повністю багатокористувацькими серверними модулями: частина фінансів/кас, CRM/боргів, постачальників і складських рухів, повернення/гарантії, розширені правила ціноутворення, керування персоналом/ролями з адмінки, LiqPay та API служб доставки.

Це не блокує запуск магазину, але ці модулі треба переносити на сервер окремими етапами.
